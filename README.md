# Number-Recognition
HandWrittenNumberRecognizeByNeuralNetwork

## 1: Abstract
this program is written by C++. The reason why I make this program is that the GKD team in SWU encourage me to program it. It uses Neural Network for training and recognizing, cv2 for GUI, socket for network communicating.

## 2: How to run it
Above all, this program needs OPENCV and SOCKET libraries.
you should first compile the "server.cpp" than compile "canva.cpp".
